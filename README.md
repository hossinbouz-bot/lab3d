# תלת-ממד במגה לאב

אתר השירות של מדפסת התלת-ממד במעבדה: הסבר, קטלוג רעיונות לפי מדור, טופס בקשה (נשלח בוואטסאפ) ותור הדפסות.

- התור נשמר בקובץ `queue.json` ומתעדכן מלשונית הניהול באתר (כתובת האתר + `#admin`).
- אין לשמור במאגר שמות עובדים, פרטי מטופלים או מספרי דגימה.
- העיצוב בשפה של מכבי שירותי בריאות: כחול `#083F92`, ורוד-פטל `#B83B7C`, גופן Heebo, כפתורים מעוגלים.

## תמונות להמחשה

התיקייה `img/` מכילה תמונות של דגמים שפורסמו ב-Printables וב-MakerWorld ברישיונות Creative Commons
(CC BY, CC BY-SA, CC BY-NC, CC BY-NC-SA, CC0). לכל תמונה שתי גרסאות: `name.webp` (960px) ו-`name-s.webp` (480px),
חתוכות ל-4:3 ומוקטנות. הקרדיט המלא (יוצר, קישור לדגם, רישיון) נמצא במערך `MEDIA` ב-`index.html`
ומוצג באתר תחת "קרדיט לתמונות". כשמוסיפים תמונה, מוסיפים גם רשומה ל-`MEDIA` עם הקרדיט והרישיון שלה,
ולא משתמשים בדגמים ברישיון ND או "Standard Digital File License".
